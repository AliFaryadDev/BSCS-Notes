## Introduction

Object-Oriented Programming (OOP) is a programming approach based on classes and objects. It organizes programs by combining data and functions into objects.

## Definition

Object-Oriented Programming (OOP) is a programming paradigm that uses classes and objects to organize data and functions into reusable units.

## Main Features of OOP

### Encapsulation
Combines data and functions into a single unit and controls access to data.

### Abstraction
Hides unnecessary implementation details and shows essential features.

### Inheritance
Allows one class to acquire properties and functions of another class.

### Polymorphism
Allows the same interface to perform different behaviors.

## Purpose

The main purposes of OOP are:

- To organize programs using classes and objects.
- To improve code reusability.
- To protect data.
- To reduce program complexity.
- To make software easier to maintain.

## Example

```cpp
#include <iostream>
using namespace std;

class Car {
public:
    void start() {
        cout << "Car Started";
    }
};

int main() {
    Car myCar;

    myCar.start();

    return 0;
}
```

## Output

```text
Car Started
```

## Advantages

- Code reusability.
- Data security.
- Better code organization.
- Easy maintenance.
- Reduced complexity.
- Flexibility and scalability.

## Conclusion

Object-Oriented Programming is a programming approach based on classes and objects. Its main features are encapsulation, abstraction, inheritance, and polymorphism. It helps developers create reusable, secure, and maintainable software.
