## Introduction

A Default Constructor is a type of constructor in C++. It is called when an object is created without providing arguments.

## Definition

A Default Constructor is a constructor that can be called without any arguments and is used to initialize an object.

## Purpose

The main purposes of a default constructor are:

- To initialize objects automatically.
- To assign default values to data members.
- To simplify object creation.
- To ensure objects start with initial values.

## Characteristics

- It has the same name as the class.
- It has no return type.
- It can be called without arguments.
- It is automatically called when an object is created without arguments.
- It can be defined by the programmer or generated by the compiler.

## Types of Default Constructors

There are two common forms of default constructors:

- **Compiler-Generated Default Constructor:** The compiler provides a default constructor when the class has no user-declared constructor.
- **User-Defined Default Constructor:** The programmer defines a constructor that can be called without arguments.

## Syntax

```cpp
class ClassName {
public:
    ClassName() {
        // Initialization code
    }
};
```

## Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int age;

    Student() {
        age = 20;
    }

    void display() {
        cout << "Age: " << age;
    }
};

int main() {
    Student s1;

    s1.display();

    return 0;
}
```

## Working

- `Student` is a class.
- `Student()` is a user-defined default constructor.
- `age` is a data member.
- `Student s1` creates an object without arguments.
- The constructor is automatically called.
- It assigns 20 to the age variable.
- `display()` shows the age.

## Advantages

- Initializes objects automatically.
- Makes object creation simple.
- Assigns initial values to data members.
- Reduces repeated initialization code.
- Improves code organization.

## Conclusion

A Default Constructor is a constructor that can be called without arguments. It initializes objects automatically and makes object creation easier.
