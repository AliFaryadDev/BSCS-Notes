## Definition

Object-Oriented Design (OOD) is a paradigm for software development in which a system is designed using objects and classes. It structures the software around real-world domain entities. 

---

## Main Concepts

| Term | Meaning | Quick Example / Note |
| :--- | :--- | :--- |
| **Paradigm** | Conceptual model / khayali namoona | Programmers **use** UML (Unified Modeling Language) diagrams to visualize it. |
| **Classes** | Blueprints arranged in a **hierarchical structure** (Base & Subclass). | Involves the concept of **inheritance**. |
| **Object** | A specific instance of a class. | A *9th class book* (with attributes like *genre: academic*). |
| **Domain Object** | Represents a single software entity. | Must be **either** *Physical* (e.g., hardware) **or** *Abstract* (e.g., a transaction) It can not both at once. |

---

## Core Workflow

> **Classification & Organization:**
> * **Classification:** Entities tay karna (identifying what objects exist).
> * **Organization:** Entities ko aapas mein jorna taake unke darmiyan taluqaat aur interaction wazeh ho sake aur system mukammal taur par kaam kare.

## Purpose

The main purposes of Object-Oriented Design are:

- To organize software into classes and objects to accurately represent real-world entities.
- To make software easier to maintain.
- To improve design reusability.
- To manage complex software systems.

## Example
### Designing Student Management System

We model a **Student Management System** by defining a `Student` class with its attributes and methods:

* **Class:** `Student` (Blueprint for every student record)
* **Attributes:** `Name`, `Roll Number`, `Marks`
* **Methods:** `Display Information()`, `Calculate Result()`



## Advantages

- Improves code organization.
- Supports code reusability.
- Makes software easier to maintain.
- Reduces complexity.
- Represents real-world entities effectively.

## Conclusion

Object-Oriented Design is a software design approach that uses classes and objects to organize programs. It helps developers create reusable, organized, and maintainable software.
