## Definition

Object-Oriented Design (OOD) is a paradigm for software development in which a system is designed using objects and classes. It focuses on organizing software around domain objects that represent both physical and abstract components of the software.

## Additional Concepts

* **Paradigm**: Conceptual model or development approach.
* **Object**: An instance of a class (for example, a *9th class book* with attributes such as *genre* like *academic*).
* **Classes**: Base class and subclass, involving concepts of **inheritance** and **hierarchical structure**.
* **Domain Objects**:
  * **Physical components**: Such as hardware.
  * **Abstract components**: Such as a transaction.
* **A domain object**:  It can either physical or abstract means non physical but can not be both.

>Classification (entities tay karna) & Organization (entities ko aapas ma joorna take un ke darmiyaan taluqaat ko or interaction ko wazeh kya jaa sake ta ke system mukmal tor par kaam kar sake)

## Main Concepts

- **Objects:** Real-world entities that contain data and behavior.
- **Classes:** Blueprints used to create objects.
- **Attributes:** Data or properties of an object.
- **Methods:** Functions that define the behavior of an object.
- **Relationships:** Connections between different objects.

## Purpose

The main purposes of Object-Oriented Design are:

- To organize software into classes and objects.
- To represent real-world entities.
- To make software easier to maintain.
- To improve code reusability.
- To manage complex software systems.

## Example

A Student Management System can be designed using objects.

- Class: Student
- Attributes: Name, Roll Number, Marks
- Methods: Display Information, Calculate Result

## Advantages

- Improves code organization.
- Supports code reusability.
- Makes software easier to maintain.
- Reduces complexity.
- Represents real-world entities effectively.

## Conclusion

Object-Oriented Design is a software design approach that uses classes and objects to organize programs. It helps developers create reusable, organized, and maintainable software.
