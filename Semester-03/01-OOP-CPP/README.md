Object Oriented Programming (CC-211)

A structured collection of lecture notes, programming examples, practical exercises, and study materials for Object Oriented Programming using C++.

Course Information

Attribute| Details
Course Title| Object Oriented Programming
Course Code| CC-211
Semester| 3rd Semester
Credit Hours| 3 (3,0)
Category| Computing Core
Prerequisite| CC-112 Programming Fundamentals
Co-Requisite| None

Course Introduction

The course aims to focus on object-oriented concepts, analysis, and software development. The basic concepts of OOP are covered in this course.

Course Learning Outcomes (CLOs)

At the end of the course, students will be able to:

CLO| Learning Outcome| Bloom's Taxonomy| PLO
CLO1| Understand principles of object-oriented paradigm.| C2 (Understand)| 1
CLO2| Identify the objects and their relationships to build object-oriented solutions.| C4 (Identify)| 2, 3, 4
CLO3| Model a solution for a given problem using object-oriented principles.| C3 (Apply)| 4
CLO4| Examine an object-oriented solution.| C4 (Examine)| 4
