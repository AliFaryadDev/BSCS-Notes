## Introduction

A Copy Constructor is an important feature of C++ that is used to create a new object by copying the data of an existing object.

## Definition

A Default Copy Constructor is a compiler-generated constructor that initializes a new object by copying the corresponding members of an existing object of the same class.

## Purpose

The main purposes of a Default Copy Constructor are:

- To create a new object from an existing object.
- To copy data members automatically.
- To initialize objects easily.
- To reduce the need for manually writing a copy constructor.
- To provide object copying functionality.

## Characteristics

- It is generated by the compiler when no user-declared copy constructor exists.
- It takes a reference to an object of the same class as its parameter.
- It copies corresponding data members from the source object.
- It performs member-wise copying.
- For pointer members, it copies the pointer value, not the dynamically allocated data.
- It is called when an object is initialized from another object of the same class.

## Syntax

```cpp
ClassName object2 = object1;
```

Here, `object2` is initialized by copying the data of `object1`.

## Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int marks;
};

int main() {
    Student s1;
    s1.marks = 90;

    Student s2 = s1;

    cout << "Original Marks: " << s1.marks << endl;
    cout << "Copied Marks: " << s2.marks;

    return 0;
}
```

## Output

```text
Original Marks: 90
Copied Marks: 90
```

## Working

- `Student` is a class containing a data member `marks`.
- An object `s1` is created.
- The value 90 is assigned to `s1.marks`.
- Another object `s2` is initialized using `s1`.
- The compiler-generated copy constructor copies the value of `marks`.
- Both objects contain the value 90.
- The values are displayed on the screen.

## Advantages

- Automatically copies object data.
- Reduces the need for writing a copy constructor.
- Makes object initialization easier.
- Saves programming time.
- Supports object copying.

## Conclusion

A Default Copy Constructor is automatically provided by the compiler when no user-declared copy constructor exists. It creates a new object by copying the corresponding data members of an existing object.
